DeskCat Playground

A browser copy of the Mac app's cat, running the same animation and behaviour code. The area below is a pretend desktop. Move your pointer around it, slowly at first.

Cat is In the box
Things to try
  • Wiggle the pointer near the boxIt rises up, paws on the rim. Get close and it bats at you.
  • Hover gently over its headPetting. Eyes close happily and it purrs.
  • Click the catIt crouches, then jumps out. The box tucks away.
  • Move slowly along the floor near itSometimes it stalks, wiggles and pounces. Sometimes it just watches.
  • Hold the pointer just above its headIt may swat at it, or jump up to catch it.
  • Swipe fast right next to itIt startles and hops away.
  • Drag the catPick it up by the scruff. The box appears; drop it in.
  • Leave it aloneIt grooms, yawns, stretches, loafs, and falls asleep.

Run the real app on your Mac

  1. Install Apple's command line tools once: xcode-select --install
  2. Download the code and run it:
git clone -b claude/intelligent-noether-dt656x \
  https://github.com/skailama/roan-forclaudeweb.git
cd roan-forclaudeweb/desk-cat
swift run

To keep it as a normal app, run ./scripts/make-app.sh and drag build/DeskCat.app into Applications.

Or download a ready-made build

  1. On GitHub, open the repo's Actions tab and pick the latest DeskCat macOS build run.
  2. Under Artifacts, download DeskCat-app and unzip it (twice).
  3. The app isn't signed with an Apple Developer ID yet, so clear the download flag once:
xattr -dr com.apple.quarantine ~/Downloads/DeskCat.app
open ~/Downloads/DeskCat.app

In this preview the cat wanders out sooner than on the Mac, so you get to see it.
